E-Commerce Order Processing System
This is a small Python project that simulates an order processing system for an online store. It handles products, orders, discounts, shipping, and generates a sales report.

Features
Validate orders (check product IDs, quantities, stock, payment status).

Calculate subtotal, discounts, and shipping fees.

Process orders (paid, pending, or rejected).

Generate a sales report with:

Total revenue, discounts, and shipping collected

Top customers

Low-stock products

Unique customers and categories

Files
order_processing.py → Main logic for products, orders, validation, processing, and reporting.

test_case.py → Contains edge case tests to check the system’s reliability.

How to Run
Clone or download the project.

Run the main file:
python order_processing.py

Run the test cases:
python test_case.py
